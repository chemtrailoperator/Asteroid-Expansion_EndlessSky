This plugin is currently complete and I hope bug free, but further development may come in future.

This plugin adds variation and complexity to the asteroid dynamic, to make mining more interesting, and more profitable early in the game to make it a viable strategy. This plugin adds 26 asteroids containing 33 minerals distributed somewhat intelligently across Human space.

Compatible with Endless Sky v.10.10 through v.10.16. Backwards and forwards compatibility is unknown, but it likely still works.
